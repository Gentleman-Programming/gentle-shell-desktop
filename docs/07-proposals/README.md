# Proposals

> Status: skeleton.

Community ideas that go beyond parity with gentle-shell. One file per proposal: Problem, Proposal, Runtime requirements, Status (`proposed` / `accepted` / `declined`). Only the maintainer moves a proposal to `accepted`.

Initial candidates:

- Agent and subagent flow as a graph.
- Interacting with a running node: inspect, steer, correct.
- Post-hoc audit: ask a finished agent why it did something one way and not another.
